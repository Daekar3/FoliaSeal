name: write-execplan
description: Write an execution plan for the current task or project in accordance with `PLANS.md`. Use when you need to create a structured plan to achieve a specific goal or complete a project, or when the user wants to use an execution plan (execplan, ExecPlan).
---

Write an ExecPlan for the next steps in the task/project or for the task(s) specified by the user. Refer to `write-execplan/PLANS.md` for requirements on how to write and execute an ExecPlan. When using this skill, ensure that you follow the structure and format outlined in `PLANS.md` to create a clear and actionable plan for achieving the desired outcome. ExecPlans should be stored in `docs/ExecPlans/` unless the repo already has ExecPlans stored elsewhere. Use a filename that reflects the task or project to which the ExecPlan pertains.
