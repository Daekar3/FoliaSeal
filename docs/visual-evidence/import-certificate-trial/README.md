# Import Certificate visual-loop trial

These files are non-normative review evidence for the portable Qt visual-loop trial. They show an isolated Import Certificate dialog with synthetic data, captured through `QWidget.grab()` on Cinnamon/X11. No real certificate, password, profile, or desktop content is included. The files are the accepted candidate-1 captures from the trial.

`empty` shows the initial state. `inspected` shows a self-signed synthetic certificate after successful inspection. Both PNGs have a matching environment and geometry JSON report. They use a 600 by 460 client, Fusion dark style, Ubuntu 10 pt font, device-pixel ratio 1.0, and screen DP-4.

The images demonstrate readable inspection facts, a masked password, and compact right-aligned Cancel/Import actions with native default emphasis on Import. Direct review found no material clipping, overlap, wrapping, or density defect at the declared minimum size. They do not prove keyboard speech, high contrast, physical DPI, or installed-package behavior. The governing project specifications remain authoritative.

The matching JSON files record the actual 600 by 460 client size, screen, style, font metrics, device-pixel ratio, password echo mode, and control rectangles. The evidence supports the current dialog composition.
