# Appearance editor visual pilot

These images are non-normative review evidence for the Appearance-editor ExecPlan. They show an isolated synthetic Library catalog and Qt dialog, captured with `QWidget.grab()` on Cinnamon/X11. No PDF, certificate, personal profile, or desktop content is included.

`before-default` is the baseline. `after-default` and `after-scrolled` are accepted candidate 4. Each PNG has a matching geometry and environment JSON report. The final captures use a 1000 by 650 client, Fusion dark style, Ubuntu 10 pt font, device-pixel ratio 1.0, and screen DP-4. The final splitter allocation changes intentionally to give the editor a usable content and preview composition.

The images demonstrate the adjacent preview, readable sample, vertically scrolling form, and stable Library-wide Cancel/Save footer. They are not pixel templates or proof of high contrast, physical DPI, keyboard focus, or installed-package behavior. The frozen `docs/UI_SPEC.md` remains the UI authority.
