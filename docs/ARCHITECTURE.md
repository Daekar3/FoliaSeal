documentation before being treated as authoritative.

- **Confirmed**: Verified from code, tests, or existing documentation.
- **Inferred**: Reasonable interpretation, but not directly stated.
- **Needs review**: Requires maintainer confirmation.
- **Debt**: Current structure is known or suspected to be problematic.
