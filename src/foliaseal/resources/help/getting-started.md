# Getting started

FoliaSeal opens one PDF at a time. Choose **File → Open** or the Open PDF button, then review the
document in the main canvas. The signing rail on the right shows what is ready and what still needs
attention.

To learn the signing path, open [Signing basics](help:signing-basics). If an action fails, see
[Troubleshooting](help:troubleshooting).

## A local-first workflow

FoliaSeal works with local files and does not require an account or network connection. Keep the
original PDF until the signed output has been verified. Use the status text and the document-signature
review surface to understand the result.
