# Certificates

A certificate identifies the signer and protects the signing operation. FoliaSeal accepts content-
validated `.p12` and `.pfx` bundles and stores managed copies according to the application settings.

## Passwords and backups

Enter the bundle password only in the certificate workflow. A remembered password is held by the
configured local credential store when available; it is not written into Help, logs, or PDF contents.
Export an encrypted backup before moving a certificate to another machine.

For local-data expectations, read [Privacy and local data](help:privacy). For the complete signing
flow, read [Signing basics](help:signing-basics).
