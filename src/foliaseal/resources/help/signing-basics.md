# Signing basics

Open a PDF, select or create the reusable signing setup that you need, and place one visible approval
signature on the document. The preview and the final signed output use the same appearance decision.

## Before signing

Choose a certificate and confirm its status in the signing rail. If placement is missing, use Place
Signature and click or keyboard-position the rectangle on the current page. The readiness status should
describe the next required action; do not sign while a blocking issue is shown.

For certificate details, read [Certificates](help:certificates). For common failures, read
[Troubleshooting](help:troubleshooting).

## Save and verify

Choose **Sign and save**, select an output path when asked, and wait for the result status. Keep the
source unchanged unless you explicitly authorize an overwrite. Reopen the result and use Document
Signatures to inspect the signatures and verification outcome.
