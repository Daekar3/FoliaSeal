# Troubleshooting

Read the status text first. It identifies the stage and the next safe action without requiring a
network connection.

## The PDF will not open

Confirm that the file exists and is a readable PDF. If the source changed while it was open, use the
source-recovery choices and keep the original until the replacement is understood.

## Signing is not ready

Check the certificate, placement, and document-safety messages in the signing rail. A missing or
expired certificate, an off-page placement, or an unreadable source is a blocking condition rather
than something FoliaSeal silently repairs.

For the first-use path, read [Getting started](help:getting-started). For credential handling, read
[Privacy and local data](help:privacy).
